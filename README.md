# Yurineko PC Viewport

Adds a docked zoom slider and optimizes desktop viewports on Yurineko.

## Installation

1. Install [Violentmonkey](https://violentmonkey.github.io/) (or Tampermonkey).
2. Install the userscript: [GreasyFork](https://greasyfork.org/en/scripts/597668-yurineko-pc-viewport-core-v2).

*Note for Chrome users: Enable **Developer mode** in `chrome://extensions` and allow user scripts in the extension settings.*
